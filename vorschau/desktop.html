NOTUA Installer

Eigener Installer im NOTUA-Look. Auf Windows ein eigenes Installationsfenster, auf dem Mac das übliche Hineinziehen in Programme, aber mit NOTUA-Hintergrund. Alles ist klickbar.

WindowsEin eigenes Fenster ohne Standard-Rahmen: Willkommen, Optionen, Installieren, Fertig. Während der Installation füllt sich links das Board Karte für Karte.
MacAuf dem Mac installiert man durch Hineinziehen. Das DMG-Fenster bekommt einen eigenen Hintergrund mit Punkte-Raster und einer NOTUA-Verbindungslinie zum Ordner Programme.
DeinstallierenUnter Windows erscheint NOTUA normal in „Apps & Features“. Das Entfernen läuft über dasselbe Fenster, deine Boards bleiben im Konto.
